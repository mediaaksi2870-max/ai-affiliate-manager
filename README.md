# AI Affiliate Manager — Official Website

This is a static website prepared for the AI Affiliate Manager project and for use as the public website associated with a TikTok for Developers app.

## Files

- `index.html` — Home
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `styles.css` — site styling
- `robots.txt`
- `sitemap.xml`

## IMPORTANT BEFORE PUBLISHING

Search for `REPLACE_WITH_` and replace every placeholder.

At minimum replace:

- `REPLACE_WITH_YOUR_EMAIL`
- `REPLACE_WITH_YOUR_WEBSITE`

Do not submit placeholder contact details or URLs to TikTok.

## Suggested public structure

After deployment:

- `https://YOUR-DOMAIN/`
- `https://YOUR-DOMAIN/privacy.html`
- `https://YOUR-DOMAIN/terms.html`

You can also configure your hosting provider to make `/privacy` and `/terms` point to those pages.

## TikTok setup

TikTok's current app-review requirements say the official website must be externally accessible and fully developed, and the Privacy Policy and Terms of Service links must be visible on the website without opening a menu. TikTok also requires URL verification for relevant app properties.

Use the public website URL as the official website in the TikTok Developer Portal, then verify the website/Terms/Privacy URL properties there.
